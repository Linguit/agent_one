# AIOps 桌面诊断工作区

`/aiops` 提供三栏中文控制台：左侧输入、真实活跃告警与持久历史；中间当前报告和实时过程；右侧步骤、工具审计、证据来源、结论引用及案例库。报告、过程与两侧长内容独立滚动。

可手工输入问题，或点击活跃告警预填问题并关联告警。合同只发送 `query` 与可选 `alertNames`，没有独立 context 字段。告警源失败会显示错误，不生成替代告警。

创建后订阅持久诊断 SSE，工具、计划和重规划均为过程记录。诊断状态与后台任务状态分别显示；Planner/Replanner 是阶段。取消使用后台 job ID，运行任务可能先显示“取消已请求”，最终状态以服务器为准。

流结束或中断会读取持久诊断、历史、证据链和案例；不会自动重新订阅。可点击“刷新状态”获取后续结果，选择历史查看已保存报告与执行链。切换历史、离开页面或退出登录会停止当前前端订阅；停止订阅不会取消后台 job。

报告使用安全 Markdown，保留固定标题、证据 ID、不确定性和 fallback 标记。工具详情默认折叠，只呈现服务端可读摘要；原始 JSON 不作为产品 UI。右栏保留证据来源、步骤/审计 ID 和报告引用。案例可查看结构化根因、建议和证据，再打开有权限的 owner 知识文档；案例是否已生成由持久 API 决定。

自动检查：`npm run frontend:desktop` 包含 1440×900 AIOps 长内容检查。这是独立临时配置下的接口夹具，不代表真实告警、模型或 MCP 验收。真实 smoke 需要可达的后端、前端、活跃告警、用户启用的真实 SearchLog MCP 及诊断提供方；在正常页面依次刷新告警、预填并创建诊断、检查报告、证据与案例文档。环境不可用时必须记录未执行。
