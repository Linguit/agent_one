# P01–P07 项目进度

| 阶段 | 完成内容 |
| --- | --- |
| **P01 安全工程基础** | 搭建后端、前端、共享契约和文档的单仓库结构。实现本地 JSON 配置读取与深合并，限制前端可读取的字段，并加入测试、构建和安全检查。 |
| **P02 API 和 SSE 契约** | 定义前后端共用的 API 数据结构、错误响应和 SSE 流式事件格式。 |
| **P03 SQLite 持久化** | 建立 SQLAlchemy 异步数据库连接、Alembic 迁移和 Repository 基础，为后续业务提供统一的 SQLite 读写方式。 |
| **P04 用户认证** | 实现后端注册、登录、登出和当前用户身份解析，为受保护接口提供认证上下文。 |
| **P05 租户隔离** | 从可信认证上下文派生 `OwnerScope`，明确资源查询和更新的归属边界，并定义向量检索和删除的租户过滤规则。 |
| **P06 百炼模型接入** | 从合并后的本地 JSON 校验模型配置，接入聊天、向量嵌入和重排序。三类接口均通过真实百炼冒烟测试。 |
| **P07 本地基础设施与 Milvus** | 搭建 etcd、MinIO、Milvus、Attu 和 Alertmanager 五个 Compose 服务。实现 Milvus 集合初始化、向量写入、检索和按文档删除，并在真实 Milvus 上验证跨用户检索和删除隔离。 |

截至 P07，知识库所需的身份、权限、模型和向量存储底座已建立。文档上传、切分、向量化、入库、检索与引用的业务流程待后续接入。
