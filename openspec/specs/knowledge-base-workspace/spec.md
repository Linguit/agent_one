# 知识库工作区

## Purpose

在桌面工作区管理当前用户的知识文档、切分预览及索引任务。

## Requirements

### Requirement: 使用真实服务管理知识文档

知识页 SHALL 使用认证 API 和 Pinia 管理知识库、文档、详情、预览和索引任务。仅一个知识库时隐藏选择器。

#### Scenario: 上传预览与删除
- **WHEN** 用户按共享文件政策和分块策略上传 Markdown 或 PDF
- **THEN** 系统将文件提交到服务端、发起索引、允许查看实际分块，并在确认删除后刷新列表。

#### Scenario: 重复摘要
- **WHEN** 服务端报告摘要冲突
- **THEN** 在明确确认后才提交覆盖请求。

### Requirement: 展示并跟踪索引任务

知识页 SHALL 约每两秒轮询活动任务，展示中文状态与失败原因，并支持重试和重建。更换所有者时清理领域状态。

#### Scenario: 活动索引状态变化
- **WHEN** 索引任务在后台完成或失败
- **THEN** 知识页更新状态并提供适用的操作。

### Requirement: 桌面行内详情与有界滚动

知识页 SHALL 默认折叠文档详情，展开后在对应行下展示。列表独立滚动，元数据和分块预览分别有界滚动，长表格支持横向滚动。

#### Scenario: 展开长文档
- **WHEN** 用户展开长文档的详情与实际切分结果
- **THEN** 浏览器在各滚动区域内展示内容，并以中文文本展示加载、空和错误状态。
