# 中文 Vue 工作台

## Purpose

为桌面用户提供统一的认证入口、工作台布局和交互基础。

## Requirements

### Requirement: 中文认证路由
系统 SHALL 通过 P04 API 注册、登录、恢复和撤销会话，并以一次首次导航初始化保护桌面业务入口。

#### Scenario: 访客进入受保护页面
- **WHEN** 未登录用户访问工作台路由
- **THEN** 跳转到登录页并保存内部返回地址

#### Scenario: 已认证用户刷新或进入公开页
- **WHEN** 当前会话通过 /auth/me 恢复
- **THEN** 允许访问工作台，登录和注册页重定向到 /chat

### Requirement: 传输与会话清理
系统 SHALL 提供基于契约的 HTTP 和 SSE 客户端，并在登出成功或当前会话收到 401 时清理已注册的受保护状态。领域数据必须驻留内存。

#### Scenario: 会话失效
- **WHEN** 当前会话收到 HTTP 401 或成功撤销
- **THEN** 清除当前身份、令牌和受保护状态

### Requirement: 桌面工作台
系统 SHALL 提供四个业务入口、仅聊天可用的会话插槽、账号、顶栏服务状态和边到边画布。根路径和未知路径返回 /chat。

#### Scenario: 切换业务入口
- **WHEN** 用户从聊天切换到其他业务入口
- **THEN** 更新标题和占位内容并移除会话区域

### Requirement: 共享状态与反馈
系统 SHALL 提供可访问的加载、空、错误和异步状态，以及支持手动关闭和三秒超时的成功、信息和错误反馈。

#### Scenario: 连续反馈
- **WHEN** 新反馈替换现有反馈
- **THEN** 重新计时，并在卸载时清除定时器
