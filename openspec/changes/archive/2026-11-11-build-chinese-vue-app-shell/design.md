## Context

现有前端提供基础页面、认证客户端和共享契约。P04 使用 Bearer 会话。

## Goals / Non-Goals

提供桌面认证工作台、共享状态组件和业务接入点。聊天、知识库、AIOps、MCP 的业务流程及移动端专用导航留待后续变更。

## Decisions

- 路由使用共享的首次初始化 Promise。登录成功仅接受已注册的工作台路径作为返回地址。
- Pinia 按应用实例管理清理回调，HTTP 和 SSE 统一处理当前令牌的 401。领域状态驻留内存。
- 工作台侧栏和画布使用独立布局。顶栏通过健康接口显示服务状态。
- 全局反馈组件管理三秒定时器及其生命周期。

## Risks / Trade-offs

服务端撤销失败时保留当前登录并显示失败，以便重试。登录凭据沿用 P04 的浏览器存储，领域数据使用内存。
