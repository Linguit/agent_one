## Context

P09 依赖 SQLite Repository、用户认证与租户隔离。

## Goals / Non-Goals

提供可恢复的后台任务和事件持久层。文档索引与 AIOps handler 由后续变更注册。

## Decisions

- 用单条 SQLite UPDATE RETURNING 领取任务，状态和事件在同一事务提交。每次领取分配独立租约标识，续租和结束都检查标识与有效期。
- worker 使用两个独立执行槽，默认租约 30 秒，轮询 0.2 秒。失败与过期按尝试次数指数退避，上限 30 秒。
- 取消排队任务即时生效。运行中任务收到取消后由 worker 协作结束；进程丢失时由过期回收完成。
- 事件游标按任务单调递增。重试已失败或已取消的任务时创建关联的新任务，保留原任务和事件。
- HTTP 只返回任务元数据。持久化错误使用固定消息，日志省略载荷和异常原文。

## Risks / Trade-offs

租约提供至少一次执行语义。业务 handler 需允许重复执行，并在收到取消时释放资源。
