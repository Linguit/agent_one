## ADDED Requirements

### Requirement: 未指定告警时独立执行日志诊断
系统 MUST 在未指定 alertNames 时跳过告警源读取，使用当前用户启用的日志 MCP 工具继续诊断；指定告警时 MUST 读取并筛选真实告警，保持告警源不可用的失败语义。

#### Scenario: 未选择告警且告警源不可用
- **WHEN** 用户未选择告警且日志查询工具可用
- **THEN** 不调用告警聚合器，继续日志查询与报告流程，不生成虚假告警证据

#### Scenario: 已选择告警且告警源不可用
- **WHEN** 用户选择了告警但告警源不可用
- **THEN** 诊断明确失败，不绕过告警读取
